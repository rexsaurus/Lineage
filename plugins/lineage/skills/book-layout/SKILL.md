# Book Layout

The book is typeset with **Typst**. The whole design lives in one file:
**`$LINEAGE/book/template.typ`**, the single source of truth. `make new` copies it
(and `book/front/*.typ`) into the project's `book/`; after the repo's template changes,
refresh the project copy with `python .claude/skills/book-generator/scripts/build_book.py sync`.
Change the design in the repo template, never by styling inside chapters, and never fork
the project copy silently. Read the template for exact function signatures.

`book/main.typ`, the title and copyright pages are **generated** by book-generator from
`book.yaml` and `data/chapters.csv`; don't hand-edit them.

## Build
```bash
make -C "$LINEAGE" draft PROJECT="$PWD"     # output/book-draft.pdf
make -C "$LINEAGE" final PROJECT="$PWD"     # output/book-final.pdf (fails on any unapproved #bridge)
python .claude/skills/book-layout/scripts/preflight.py output/book-final.pdf --trim 7x10 --printer kdp --color bw
python .claude/skills/book-generator/scripts/build_book.py chapter chapters/03-x.typ    # one chapter: output/preview-03-x.pdf
python .claude/skills/book-generator/scripts/build_book.py chapter chapters/03-x.typ --final --pages   # + page images to share
```
Draft mode shows image IDs, editor notes and highlighted bridges. Final mode **refuses to
compile while any unapproved `#bridge` remains**, by design. After every build, render
pages (`pdftoppm -r 60 -png`) and look: a chapter opener, a page with a plate, a verso/recto
spread, the contents and the index. While working on one chapter, preview it alone with
`build_book.py chapter` instead of rebuilding the book. To share pages outside the PDF,
`--pages` writes one JPEG per page to `output/pages/<name>/`, at the largest ppi that keeps
the long side within 2048 px (the limit of most photo-sharing sites; `--ppi N` to change);
build `--final` so no draft marks show, and label any illustrations in the post as such.

## Design
| Element | Spec |
|---|---|
| Trim | `book.yaml` → `print.trim`; default **7×10 in** (6×9 if nearly text-only) |
| Margins | inside 0.875 in, outside 0.625 in, top and bottom 0.85 in; raise the inside (gutter) to 1 in above 400 pages |
| Body | EB Garamond (installed name "EB Garamond 12"), justified, hyphenated, old-style figures; 11 pt single-column, 10.5 pt two-column; first-line indent, no space between paragraphs |
| Columns | **per chapter**: `columns: 1` for narrative chapters, `columns: 2` for research-dense ones (`data/chapters.csv` → `columns`) |
| Chapter opener | **always starts on a recto**; **no running head**; "Chapter N" in spaced caps, title in spaced capitals with a short rule, then the **place-and-years line** (setting · dates), the poetic summary in italic, **optional epigraphs** (italic, source in spaced small caps); the opener spans both columns |
| First paragraph | **drop cap**: `#opening[lead words][rest]`, a red three-line initial with the lead words in small caps (red prints gray in B&W) |
| Section breaks | `#sectionbreak`: a centered **❧** ornament |
| Parts | `#part("Those Who Came Before")` on a recto, no folio |
| Running heads | verso: book title; recto: chapter title; spaced small caps; none on openers or blank pages |
| Folios | centered at the foot; **roman in front matter, then arabic restarting at 1** at chapter one (`#show: main-matter`); **no folio on blank pages**, part pages, title, copyright or dedication |
| Page count | the final page count is **even** (book-generator pads with a blank) |
| Long quotes | `#verbatim[...]`: indented block, no italics |
| Plates | `#plate(path, caption:, width:, span:, id:)` framed, floated top or bottom, spaced-caps caption; `span: false` = one column; `#plate-pair` for two; `#photo(...)` inline with date/place/comment |
| Family devices | `#descent(..)` line of descent at the foot of the opening page; `#records(..)` THE RECORDS in small type; `#photo-addendum(..)` the photographs page |
| Notes | `#footnote[...]` for reader explanations only; `#note[...]` prints in draft only |
| Index | two columns, generated by `#make-index()` |

Typst gotchas: verse line breaks inside an epigraph are `\`; the paragraph after a plate or
break can start flush with `#flush[...]`; floats only land on or after their anchor's page,
so to force an image onto a page move its call to a paragraph on that page; several big
plates at a chapter's end will float past the text (make one single-column or move it up).

## Images on the page
photo-processor inserts the calls; this skill decides how they sit.
- No image on a chapter opener unless it's a deliberate frontispiece; at most one per page
  in running text; never a page that is only a plate in the middle of a chapter.
- Portraits about 3.9 in wide, landscapes about 4.4 in, maps full width; never wider than
  `max_print_width_in`.
- `#photo(..., width: 60%, placement: none)` pins a small or portrait photo exactly where it
  sits in the text: use it for a photo the text points to ("this one here").
- **Resolution: 300 ppi at printed size; 200 ppi is a hard floor** (preflight computes it).
  Below 200: print smaller or get a better scan. Never upscale.
- Illustration captions must carry their marking ("illustration" / "as the family told
  it") in the final PDF, not just in drafts.
- B&W interior: images go in grayscale; check contrast on a test print.

## Front and back matter
Front (roman folios): half-title (optional) · title · copyright · dedication · contents ·
introduction by the author (foreword first if someone else wrote one).
Back (after the chapters): **timeline** (`90-timeline.typ`) · **glossary for readers**
(`92-glossary.typ`) · **where the records are** (`91-where-the-records-are.typ`) · **about
the recordings** (`93-about-the-recordings.typ`) · **acknowledgments**
(`94-acknowledgments.typ`) · **index**. book-generator writes them into `main.typ` in that
order when they exist.

## Index
Terms are marked with `#idx(...)` **as the text is written** (chapter-index-builder); the
index is generated with real page numbers at build time by `#make-index()`, so it stays
right when pages move.

## Printer notes
- **KDP paperback**: min 24 pages, even count, embedded fonts, no crop marks; hardcover min 75.
- **IngramSpark** prefers PDF/X-1a or X-3; convert with Ghostscript or Acrobat if rejected.
- **Full bleed** needs 0.125 in extra on outside, top and bottom; only if the author asks.
- The **cover** is a separate file sized by the printer's calculator once the page count is final.
- Rough estimate: narrative words ÷ 330 ≈ 7×10 text pages, plus images and matter.
